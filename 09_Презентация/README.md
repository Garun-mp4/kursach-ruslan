# Материалы для защиты

- `Презентация_к_защите.pptx` — редактируемые слайды, 15 страниц.
- `Презентация_к_защите.pdf` — постраничная копия слайдов для просмотра и печати.
- `Заметки_докладчика.md` — краткий сценарий выступления примерно на 9:45.
- `media/симуляция.mp4` — отдельная запись виртуального прогона, на которую ведет относительная ссылка слайда 11.
- `source/` — исходник сборки презентации и скрипт подготовки PDF из финальных рендеров.

Чтобы показать видео, откройте `media/симуляция.mp4` из каталога рядом с PPTX. Перед защитой проверьте воспроизведение на том компьютере, на котором будет открываться презентация: встроенный проигрыватель PowerPoint в этом окружении не проверялся.

Материалы и результаты описывают виртуальное моделирование. Физический прототип не изготовлялся.
