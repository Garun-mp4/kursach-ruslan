# M4-v1.1 independent-validation debug archive

This set used the M4-v1.1 detector before known-color core splitting. It exposed two merged candidate failures and one false candidate. The frames were inspected to diagnose those failures, so their seeds are excluded from the M4-v1.2 acceptance set. M4-v1.2 adds RGB-derived splitting of an oversized background component only when at least two geometrically plausible, known-color cores exist; otherwise the candidate is rejected.
