# M2 — модель и геометрия

M2 формирует параметрическую учебную модель манипулятора SCARA R–R–P–R. Это не CAD-модель серийного изделия и не физически измеренный прототип.

## Источник параметров

Единственный редактируемый набор чисел находится в `02_Спецификация/параметры_системы.yaml`. MJCF, реестр параметров, таблица узлов и инженерные расчеты генерируются из него.

## Воспроизведение

Из корня проекта в CPython 3.12.10 x64:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\04_Программа\m2\requirements.txt
.\.venv\Scripts\python.exe .\04_Программа\m2\build_model.py
.\.venv\Scripts\python.exe .\04_Программа\m2\validate_ssot.py
.\.venv\Scripts\python.exe .\04_Программа\m2\draw_m2_diagrams.py
```

Валидатор проверяет схему SSOT, единицы и основные геометрические ограничения, повторно строит ожидаемый MJCF, сравнивает исходник байт-в-байт и компилирует его MuJoCo. JSON-отчет и рендеры сохраняются в `99_Рабочие_материалы/m2_validation/results/`.

## Редактируемые схемы

Исходники `.drawio` находятся в `03_Модель_и_схемы/source/`, экспортированные PNG/SVG — в `03_Модель_и_схемы/exports/`. Схемы генерируются из SSOT для соблюдения размеров; для изменения чисел правьте YAML и повторяйте сборку.

## Границы этапа и продолжение

M2 зафиксировал геометрию и начальный физический baseline. Аналитические FK/IK, сингулярности и точечная рабочая область реализованы и проверены отдельно в M3; см. `02_Спецификация/Кинематика.md` и `04_Программа/kinematics/`. Они не включают collision-free путь или полный габарит захвата. В следующих этапах остаются computer vision, планирование траекторий/коллизий и полный цикл сортировки.
