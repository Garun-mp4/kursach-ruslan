## Реализация

- Добавлен необязательный recorder полного `mjSTATE_INTEGRATION` потока в `evaluator_private/recording/`; он не подает данные в контроллер и не меняет RGB sensor views.
- MP4 рендерится только после завершения controller run по сохраненным состояниям. Добавлены три независимых зрительских ракурса: общий, сверху и крупный план TCP.
- HUD показывает маркировку «ПРОГРАММНАЯ СИМУЛЯЦИЯ», run ID, simulation time, состояние FSM, активный track, публично оцененный цвет и число controller-confirmed размещений. Ground truth evaluator в HUD не передается.
- Ключевые состояния сохраняются отдельными PNG вместе с simulation timestamp, event IDs и ближайшим индексом кадра.
- Контактные пары агрегируются в эпизоды по физическим шагам 0,002 s. Время начала, последнего положительного sample, обнаруженного закрытия и длительность имеют раздельную семантику.
- Формат и визуальное назначение журналов M9 описаны в `02_Спецификация/Запись_и_телеметрия.md`.

Это подтверждает эквивалентность только для указанной пары запусков на ПК разработки; это не межплатформенный тест и не приемочная выборка M9.

## Журналы и M9 readiness

- Все run outputs из M7 `relative_outputs` связаны с записью путями и SHA-256: controller events, суставная/TCP telemetry, perception snapshots, M5 plans, evaluator object telemetry, physics-step contact episodes и evaluator report.
- Запуск содержит 82 405 physics-step contact samples, агрегированных в 38 контактных эпизодов; sampled object telemetry и итог evaluator сохранены отдельно от управляющих данных.
- Для этого run источник подтверждает `physical_sort_success_count=1`, `physical_sort_failure_count=0`; эти числа характеризуют один демонстрационный run, а не эффективность алгоритма.
- Контактная диагностика занимала 19,2179 s суммарного wall time в течение 82 405 вызовов (~0,233 ms на вызов в этом run). Ее время является диагностикой; controller принимает решения по simulation time. Нужна повторная оценка стоимости при увеличении масштаба кампании M9.
- Финальные знаменатели, acceptance thresholds и статистические выводы остаются задачей M9.

### Повторный аудит

В ходе аудита обнаружены и исправлены: тесная компоновка боковых панелей, недостаточно информативный крупный план, неоднозначность временной границы physics-step контактного эпизода и сериализация run path в тестах с временным output-каталогом вне репозитория. Последнее исправлено fallback-ом на абсолютный путь только для внешних каталогов; проектные пути остаются относительными. Первый regression проход выявил 11 исключений по одному path root cause; после исправления все 38/38 integration тестов прошли. `avc1` encoder в локальной OpenCV-сборке отсутствует, поэтому фактический проверенный codec — `mp4v`; этот fallback указан в manifest и документации. Шесть доступных keyframes соответствуют событиям фактического успешного run.
