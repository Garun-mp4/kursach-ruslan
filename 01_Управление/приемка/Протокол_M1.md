- ПК: Windows 11 x64, Intel Core i5-11400H, 8 GB RAM, NVIDIA GTX 1650 Max-Q + Intel UHD. Renderer работал с OpenGL-графическим контекстом.
- Повтор чистой установки: новое виртуальное окружение CPython 3.12.10 создано без использования системного site-packages; установка requirements.txt прошла успешно. Полный вывод установки и повторного запуска сохранен в results/clean_install_and_rerun.log.
- Команда повторения из каталога mujoco_m1: `py -3.12 -m venv .venv`; затем ` .\.venv\Scripts\python.exe -m pip install -r requirements.txt`; затем ` .\.venv\Scripts\python.exe run_m1_feasibility.py`. Зафиксированный чистый прогон выполнен в отдельном окружении `.validation_env`; оно сохранено локально как доказательство. Портативные команды выше создают независимое `.venv`.
- Режим рендеринга: offscreen через native OpenGL-контекст установленного графического драйвера, без видимого окна GUI. Это не подтверждает работу CPU software-render backend: он отдельно не устанавливался и не проверялся. GPU-вычисления физической симуляции не требуются, но для данного режима рендера необходим совместимый OpenGL-контекст и драйвер.
- Случайной генерации в стендах нет; seed не применялся.

## Интерпретация

Выбранная версия движка пригодна для последующей разработки: свежая установка прошла, revolute и prismatic актуаторы дошли до заданных поз в пределах, offscreen RGB-кадр возвращен, а физическая контактная модель подняла и отпустила свободный объект без weld-связи. Два отрицательных контроля не были ошибочно засчитаны как успешный захват. Общий `overall_status=PASS` означает, что протокол стенда выполнен с ожидаемыми отрицательными исходами и записанным ограничением; он не означает, что система сортировки уже работает.

Шаг 0.01 s не принят как безопасная настройка: на этом тесте контакт не подтвердился. Значение 0.002 s — только успешная точка конкретного стенда, не готовая настройка финальной модели. В M2/M7 необходимо повторить sensitivity check на окончательных массах, контактных геометриях, механике и solver settings. Отдельно должны быть проверены перенос по XY и полная рабочая рука; M1 делал минимальные стенды отдельных возможностей.

Скорость 58.1× realtime относится только к простой модели gripper без рендера на этом компьютере. Запись видео выполнялась в меньшем темпе и не является оценкой длительности будущей кампании. Переносимость OpenGL на другом компьютере не доказана; на целевом ПК повторить clean install и renderer check.
