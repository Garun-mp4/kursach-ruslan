# Пример видеозаписи M8

Каждый дочерний каталог с именем `run_id` содержит MP4 и контрольные кадры, созданные из состояния того же виртуального прогона, а также JSON-манифест со временем симуляции, codec, настройками изображения, хешами исходных логов/конфигурации и результатом проверки полного декодирования.

Исходные controller logs находятся в `05_Верификация/integration/runs/<run_id>/controller/`. Сериализованные состояния для зрительского воспроизведения лежат отдельно в `05_Верификация/integration/runs/<run_id>/evaluator_private/recording/`; они не подаются алгоритму управления. Состав журналов и временные частоты описаны в `02_Спецификация/Запись_и_телеметрия.md`.

Повторная запись из корня проекта:

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) '04_Программа')
& '99_Рабочие_материалы/integration/.venv/Scripts/python.exe' `
  '04_Программа/run_m7.py' --mode batch --scenario single_red_center `
  --physics-profile nominal --record `
  --out '05_Верификация/integration/runs' `
  --recording-out '06_Медиа/проверка_записи'
```

На текущей локальной OpenCV-сборке H.264 encoder недоступен. При генерации пробуется H.264 `avc1`; при недоступности используется MPEG-4 Part 2 `mp4v`, который должен быть явно указан в `Запись_и_связанные_логи.json` и полностью проверен декодированием.

Проверить сохраненную запись и хеши исходного прогона из корня репозитория:

```powershell
& '99_Рабочие_материалы/integration/.venv/Scripts/python.exe' `
  '05_Верификация/integration/verify_recording_lineage.py' `
  --run-id '<run_id>'
```

Проверка создает рядом с записью `Проверка_целостности.json`: в нем сверяются run ID, SHA-256 pre-recording manifest, state stream, MP4 и всех M7 output-файлов, а также полный decode видео и соответствие числа кадров timeline/state stream.

Видеозапись показывает программную симуляцию. Физический прототип не создавался, физические измерения не выполнялись.
