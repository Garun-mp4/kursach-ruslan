# Архитектурная диаграмма M1

Актуальный редактируемый draw.io source: `Архитектура_M1.drawio`. Его экспортные изображения: `Архитектура_M1.svg` и `Архитектура_M1.png`.

Диаграмма показывает концептуальные потоки и границу данных контроллера/evaluator. Это не физическая схема соединений и не геометрический чертеж; они не относятся к текущему этапу.

Первый Mermaid-импорт и его исходники сохранены отдельно в `../../99_Рабочие_материалы/superseded/m1_diagram_first_draft/`; использовать следует только актуальный файл выше.
