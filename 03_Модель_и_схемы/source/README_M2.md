# Исходники M2

`scara_color_sorter_m2.xml` — сгенерированный MuJoCo MJCF. Редактировать вручную не следует: он строится скриптом `04_Программа/m2/build_model.py` из `02_Спецификация/параметры_системы.yaml`.

Файлы `*_M2.drawio` — редактируемые инженерные схемы. Они показывают размерную компоновку ячейки, координатные соглашения и камеру/грубую радиальную проверку. Они также строятся из SSOT через `04_Программа/m2/draw_m2_diagrams.py`.

В `../exports/` сохранены PNG и SVG, экспортированные draw.io Desktop. SVG/PNG содержат встроенную диаграмму draw.io и открываются для редактирования в приложении. Рендеры, снятые непосредственно из MuJoCo, размещены рядом как отдельные наглядные материалы.

Положение и размеры схем являются проектными параметрами виртуальной модели. Они не подтверждают достижимость поз, качество распознавания, отсутствие столкновений на всей траектории или физическую изготовленность.
