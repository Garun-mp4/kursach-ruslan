# Исходники пояснительной записки M10

- `Пояснительная_записка.md` — полный редактируемый текст и ссылки на фигуры.
- `build_m10_docx.py` — воспроизводимая сборка DOCX из Markdown и изображений с применением шаблона стилей.
- `prepare_m10_tables.py` — формирование сверки чисел из SSOT/M3/M9 и контроль основных чисел записки.
- `update_m10_toc.py` — извлечение фактических печатных страниц заголовков из экспортированного PDF для статического оглавления.
- `M10_шаблон_стиля_АГТУ.docx` — очищенная основа оформления, подготовленная по переданному пользователем референсу. Демонстрационное содержание референса в записку не переносилось.
- `../figures/00_Эмблема_АГТУ_из_референса.png` — используемая титульным листом эмблема.

## Воспроизводимая сборка

Команды запускаются из корня репозитория в PowerShell. Сначала установите зависимости M10 в `.venv` и при необходимости обновите таблицы и компоновочные иллюстрации из утвержденной конфигурации:

```powershell
& '.venv/Scripts/python.exe' -m pip install -r '08_Записка/source/requirements_m10.txt'
& '.venv/Scripts/python.exe' '08_Записка/source/prepare_m10_tables.py'
& '.venv/Scripts/python.exe' '08_Записка/source/regenerate_m10_layouts.py'
```

Прямые зависимости инструментов M10 закреплены в `08_Записка/source/requirements_m10.txt`: `python-docx==1.2.0`, `pypdf==6.10.0` и `PyYAML==6.0.3`.

Первичная сборка создает DOCX без карты страниц; затем DOCX экспортируется в PDF, после чего обновляется карта оглавления. Финальная сборка использует JSON-карту страниц, а после повторного экспорта карта проверяется ещё раз. Если отредактированный документ меняет разбиение на страницы, цикл сборки и экспорта нужно повторить до стабилизации карты.

```powershell
& '.venv/Scripts/python.exe' `
  '08_Записка/source/build_m10_docx.py' `
  --input '08_Записка/source/Пояснительная_записка.md' `
  --output '08_Записка/Пояснительная_записка.docx' `
  --project-root '.'

# После экспорта первичной сборки в PDF:
& '.venv/Scripts/python.exe' `
  '08_Записка/source/update_m10_toc.py' `
  --pdf '08_Записка/Пояснительная_записка.pdf' `
  --markdown '08_Записка/source/Пояснительная_записка.md' `
  --output '08_Записка/review/Оглавление_M10.json'

# Финальная сборка с фактическими страницами оглавления:
& '.venv/Scripts/python.exe' `
  '08_Записка/source/build_m10_docx.py' `
  --input '08_Записка/source/Пояснительная_записка.md' `
  --output '08_Записка/Пояснительная_записка.docx' `
  --project-root '.' `
  --toc-pages '08_Записка/review/Оглавление_M10.json' `
  --body-page-start 4
```

Для воспроизводимого экспорта PDF требуется установленный LibreOffice с `soffice.com`, доступным через `PATH`. Экспортируйте DOCX во временный каталог, проверьте результат и только затем заменяйте финальный PDF:

```powershell
$soffice = (Get-Command soffice.com -ErrorAction Stop).Source
$out = Join-Path $env:TEMP 'm10-pdf-export'
New-Item -ItemType Directory -Force -Path $out | Out-Null
& $soffice --headless --convert-to pdf --outdir $out '08_Записка/Пояснительная_записка.docx'
```

После экспорта снова запустите `update_m10_toc.py` и сравните JSON с картой, использованной при финальной сборке. Если карта изменилась, повторите сборку DOCX и экспорт до стабилизации. Текущий документ проверен на стабильность: 31 страница, тело начинается с печатной страницы 4, карта содержит 16 основных заголовков.

Если нужно повторно получить PNG диаграмм из редактируемых Draw.io исходников, используйте установленное приложение draw.io:

```powershell
& 'C:/Program Files/draw.io/draw.io.exe' -x -f png --disable-gpu -e -b 16 -s 2 -o '08_Записка/figures/03_Компоновка_ячейки_M7.png' '08_Записка/source/robot_layout_m7.drawio'
& 'C:/Program Files/draw.io/draw.io.exe' -x -f png --disable-gpu -e -b 16 -s 2 -o '08_Записка/figures/04_Размерный_вид_M7.png' '08_Записка/source/robot_dimensions_m7.drawio'
```

`tables/source__*` — побайтные копии исходных таблиц и агрегата M9. Иллюстрации `figures/` скопированы из редактируемых материалов M1–M9; оригиналы и исходники диаграмм остаются в своих каталогах проекта. Титульные реквизиты записки перечислены в `01_Управление/Реквизиты_и_источники.md`. Назначение и сроки сдачи/защиты оставлены пустыми, так как официальное индивидуальное задание с датами не найдено. Переданный DOCX используется как заданный пользователем референс оформления; он не объявляется официальной методичкой кафедры.

Для построения PDF требуется установленный LibreOffice. Рендеры страниц для визуального контроля сохраняются только в `review/` и не являются исходными данными записки.
